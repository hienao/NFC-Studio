# 读取和写入第一枚标签

[首页](../../README.zh-CN.md) · [English](../getting-started.md) · [常见问题](faq.md)

## 准备

使用具备 NFC 硬件的 Android 7.0 或更高版本设备，在系统设置中开启 NFC。天线位置因机型而异，常见于摄像头附近或背部中央。建议先使用空白、可写、兼容 NDEF 的标签测试；实际能力因手机和标签而异。

## 读取

1. 打开 NFC Studio，保持应用在前台。
2. 将标签靠近 NFC 天线，等待结果；必要时缓慢调整位置。
3. 查看技术类型、NDEF 支持情况、容量和记录详情。并非每枚标签都提供全部字段；显示标识符或技术类型不代表可以读取受保护内容。

## 写入

1. 打开写入页面，选择文本、网址等受支持的记录类型。
2. 输入不含隐私的测试内容，例如 `https://example.com`，检查记录。
3. 开始写入，将兼容的可写标签贴近天线。
4. 保持标签稳定，等待写入和回读验证完成。“写入完成”与“验证成功”是不同结果，请确认结果后再移开。
5. 再次读取标签确认内容。如果另一台设备没有触发预期操作，检查它是否支持对应 NDEF 记录。

写入会替换标签现有 NDEF 内容，请先备份需要保留的内容。擦除只清空受支持的 NDEF 内容，不解除硬件锁或重置受保护凭证。对于支持永久只读的标签，该锁定操作不可撤销。

## 复用与备份

将常用内容保存为模板，在“我的标签”中添加名称、分组和备注。通过应用的数据工具导入或导出本地 JSON；分享前检查导出范围，导入时会跳过重复记录。导出文件可能包含个人内容，不适合附在公开 Issue 中。

二维码导入会在使用时请求相机权限，通过随应用打包的模型在本机识别受支持内容；不希望授权时可以粘贴。第三方 SDK 诊断数据说明见[隐私政策](https://hienao-apps.pages.dev/nfc-studio/privacy/)。

## 高级工具

Pro 提供批量写入、对比、报告及受支持的认证与安全工具。仅使用你有权使用的密码或密钥。受支持的 MIFARE 数据复制跳过制造商块和扇区尾块，不复制 UID、密钥，也不复现可用的门禁或支付凭证；访问限制和硬件兼容性仍然适用。
