# Help improve NFC Studio / 参与改进

English and Chinese feedback is welcome. This repository contains public documentation and feedback; application source is private.

## Report a problem

Read the [FAQ](docs/faq.md) and search [existing issues](https://github.com/hienao/NFC-Studio/issues) first. Include app version, Pro status, Android/device details, tag type, reproduction steps and expected versus actual results. Use the issue forms for bugs and feature requests. Suggestions do not imply a delivery commitment.

Public issues are visible to everyone. Remove tag UIDs, personal NDEF records, Wi-Fi credentials, passwords, keys and identifying information. Never attach a real backup or payment receipt. For sensitive reports, email [shiwentao666@gmail.com](mailto:shiwentao666@gmail.com).

## Improve documentation

Open a PR for corrections or translations. Keep product facts aligned across all nine introductions and synchronize English/Chinese guides where relevant. Preserve language selectors and clearly label guide languages. Use fictional data and only material you have the right to share. Document asset sources. Verify links and image references and check desktop/mobile layout; no application build is needed.

Do not add app code, binaries, development/release configuration, real tag dumps or private history. Keep installs linked to Google Play and privacy/website links pointed at the central official site. This repository does not grant an open-source license to the application or its assets.
